Flash over USB

Plug the panel in with a USB-C data cable, then:

Needs Chrome, Edge or another Chromium browser. Safari and Firefox cannot talk to the serial port. Everything runs locally — the firmware is flashed straight from this page.

After flashing, connect to the panel's setup Wi-Fi. Join the open network whose name starts with reterminal-e1003-. No password is required.
Configure the network:
  1. The setup page should open automatically. If it does not, browse to 192.168.4.1.
  2. Enter your Wi-Fi details. The panel reboots and paints the dashboard.
  3. Add it in Home Assistant. Home Assistant sets a unique API encryption key during the first connection.
Open-source setup image. This build contains no home Wi-Fi, AP password, API encryption key, or Home Assistant entity ID. The setup window stays available for 24 hours and reopens after a reboot. Source and build instructions are in the repository.

Connect Home Assistant

After adding the ESPHome device, import the optional light-sync blueprint directly in Home Assistant. No Container file access or YAML package is required.

Import Home Assistant blueprint

A real light is optional. The panel's state and value text entities can be edited directly for display-only use.

Without a browser

Both ESPHome build artifacts are attached to every release:

  • firmware.factory.bin — full image, flash at offset 0 with esptool for a first install.
  • firmware.ota.bin — application image for the captive-portal updater after initial setup.

The published firmware has no persistent native OTA service. Use USB or the captive-portal updater for recovery.

Firmware is built by GitHub Actions from the tagged source; the same files are attached to the matching release.
